# Dira 🏠

אתר לניהול דירת שותפים: תורנות ניקיונות, רשימת קניות משותפת, מלאי, תקלות, לוח מודעות, סקרים ופרטי הדירה.
הוא עובד בכל טלפון (אנדרואיד ואייפון) ואפשר להתקין אותו למסך הבית כ־PWA.

## מבנה
- `public/`: הממשק (HTML/CSS/JS נקי, בלי שלב build)
- `functions/api/[[path]].js`: ה־API (Cloudflare Pages Functions)
- `wrangler.toml`: הגדרות, כולל החיבור למסד הנתונים D1 (`DB`)
- הטבלאות נוצרות אוטומטית בבקשה הראשונה, ולכן אין צורך במיגרציות

## פריסה ל־Cloudflare Pages
1. מסד D1 בשם `dira-db` כבר קיים, וה־ID שלו מוגדר ב־`wrangler.toml`.
2. ב־Cloudflare: Workers & Pages, אחר כך Create, Pages, ואז Connect to Git. בוחרים את הריפו.
   - Framework preset: None
   - Build command: ריק
   - Build output directory: `public`
3. Deploy. ה־binding של D1 נקרא מתוך `wrangler.toml`.

## הרצה מקומית
```bash
npm install
npx wrangler pages dev public --d1 DB=local-dira
```

## איך זה עובד
- **כניסה:** יוצרים דירה ומקבלים קוד הזמנה בן 6 תווים. השותפים מצטרפים עם הקוד או עם קישור. כל שותף מקבל טוקן אישי שנשמר בדפדפן, בלי סיסמאות. לכניסה ממכשיר נוסף משתמשים ב"קישור כניסה אישי" שבהגדרות.
- **תורנות שבועית:** תורן אחד בכל שבוע (ראשון עד שבת) לפי סדר השותפים. התור עובר הלאה רק כשמסמנים "בוצע". מי שלא סיים נשאר תורן גם בשבוע הבא, עד שהוא מסמן. כשמסיימים, הבא בתור מתחיל ביום ראשון הקרוב.
- **התראות (Web Push):** בתחילת התור, תזכורת מיום חמישי, ותזכורת יומית כשיש איחור. בנוסף התראה על "אני בסופר" ועל בקשת החלפה. ה־workflow `reminders.yml` מריץ בדיקה פעם ביום, והאתר בודק גם בכל כניסה. כל התראה נשלחת פעם אחת ביום לכל היותר. באייפון ההתראות עובדות רק אחרי התקנה למסך הבית.
- **מלאי:** מוצר שמסומן "עומד להיגמר" או "נגמר" נכנס לרשימת הקניות לבד. כשמסמנים אותו כנקנה, הוא חוזר ל"יש".
- **"אני בסופר":** כל השותפים רואים באנר במשך 90 דקות.
